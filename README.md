## 02 / 构建方式 · How I Build

我关心的不只是模型能做什么，更是它能否在具体场景下解决问题。

| 环节 | 关注重点 |
| :--- | :--- |
| **01 · Discover** | 识别用户与业务问题，确定约束、优先级和成功标准 |
| **02 · Design** | 设计产品流程、交互与人工 / AI 协作边界 |
| **03 · Build** | 借助 AI Coding，将想法快速变成可使用的产品原型 |
| **04 · Evaluate** | 通过测试与 Bad Case 回顾，检查质量、成本、延迟并持续迭代 |

<br>
